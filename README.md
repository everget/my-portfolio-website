# My Portfolio Website

A personal developer portfolio built with React 19 and Vite. Features a skills showcase, project gallery, responsive mobile-friendly layout, dark/light theme, and full i18n support across 25 locales in 23 languages (EN-US, EN-GB, RU, UK, DE, FR, ES, IT, NL, PT-BR, PT-PT, PL, TR, ID, MS, VI, JA, ZH, KO, TH, AR, HE, HI, HY, KA).

[Live demo](https://everget.github.io/my-portfolio-website/)
